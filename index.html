¿Qué es una skill?

Una skill es una capacidad que se adjunta a un agente para ampliar lo que puede hacer: navegar por la web, leer documentos, gestionar calendarios, etc. Un mismo agente puede combinar varias skills, y una skill puede estar habilitada en muchos agentes a la vez.
